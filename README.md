# 初中生物必背 · 110句闪卡

一个专门为初中生备考生物设计的手机端记忆卡片应用，基于 GitHub Pages 部署，打开即用。

## 功能特点

- **110句完整收录**：覆盖初中生物全部核心知识点
- **三种学习模式**：
  - 📚 **顺序学习**：按编号逐句系统复习
  - 🎲 **随机抽测**：打乱顺序检验真实掌握度
  - 🔁 **错题重练**：只复习标记为"需复习"的句子
- **填空式记忆**：卡片正面显示挖空句子，点击显示答案，重点高亮
- **进度自动保存**：使用浏览器本地存储，刷新不丢失
- **全句浏览**：支持按分类筛选和关键词搜索
- **手机端优化**：触屏手势支持（左右滑动切换卡片）

## 使用方法

1. 手机或电脑浏览器打开页面
2. 选择学习模式开始记忆
3. 点击卡片或"看答案"按钮显示完整答案
4. 根据掌握情况点击"记住了"或"需复习"
5. 随时进入"错题重练"巩固薄弱环节

## 技术说明

- 纯前端实现，单 HTML 文件，无需服务器
- 数据直接内嵌，无需网络请求加载
- 使用 localStorage 保存学习进度
